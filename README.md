#  Shooniverse

### A World of Shooz. Walk Your Own Orbit.

Shooniverse is a shoe-focused e-commerce platform built around unique designs, curated collections, and a distinctive shopping experience.

The idea is simple: create a space where different styles, designs, and shoe collections come together, making it easier to discover and explore shoes.

---

##  About the Project

Shooniverse explores the intersection of footwear, design, and technology.

Beyond being an online shopping experience, the project is an exploration of how a shoe-focused digital platform can combine visual identity, product discovery, and intuitive interactions.

The platform features a distinctive space-inspired visual direction, with an emphasis on clean layouts, product presentation, and an engaging shopping experience.

## ✨ Features

- **Product Catalogue:** Browse available shoe collections.
- **Category Exploration:** Discover different shoe styles.
- **Product Discovery:** Explore individual products and their details.
- **Shopping Cart:** Add and manage selected products.
- **Checkout:** A dedicated shopping checkout experience.
- **Responsive Interface:** Designed to work across different screen sizes.
- **Orbit-inspired Design:** A distinctive visual identity built around the Shooniverse brand.

## 🚀 Getting Started

To run Shooniverse locally:

**1. Clone the repository**

```bash
git clone https://github.com/PleasantRon/Shooniverse.git
```

**2. Navigate into the project directory**

```bash
cd Shooniverse
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
